# MediCare AI Website

A responsive, front-end academic prototype for a guided health-intake website.

## Run it
1. Extract `MediCare_AI_Website.zip`.
2. Open the `medicare_ai_website` folder.
3. Double-click `index.html` (or open it with Chrome/Edge).

No installation, Python, Node.js, or API key is required.

## Files
- `index.html` — website pages and layout
- `style.css` — responsive design
- `script.js` — navigation, guided intake chat, and local demo storage

## Included
Overview dashboard, AI-style guided intake chat, health assessment form, health records, and project/about page. Data is saved in the browser's local storage for demo purposes.

## Important
This is a front-end educational prototype only. It does not connect to a real AI model, diagnose illness, prescribe medication, or replace a qualified healthcare professional. Do not enter sensitive personal health information on a shared device. For severe or rapidly worsening symptoms, seek urgent medical help.
